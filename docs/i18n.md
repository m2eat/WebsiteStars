# Internationalization / 国际化

WebsiteStars includes English and Simplified Chinese. `lib/i18n.ts` reads the first browser language preference (`navigator.languages[0]`, then `navigator.language`); Chrome's UI locale is a fallback when navigator language is unavailable. Chinese locales map to `zh-CN`; other languages fall back to `en`. Reopen extension pages after changing browser language preferences.

React pages set `<html lang>` and their title before mounting, and use React Aria's `I18nProvider` for built-in accessibility strings. Dates and numbers use `Intl` with the resolved locale. Native manifest descriptions use Chrome's `_locales` catalogs and `default_locale: en`.

## Catalogs

- `lib/locales/en-ui.ts`: library, chat, shared components, Markdown controls.
- `lib/locales/en-settings.ts`: settings, detail view, index status.
- `lib/locales/en-extension.ts`: injected buttons and background menus.
- `lib/locales/en-runtime.ts`: system errors, persisted progress, and warnings.
- `public/_locales/*/messages.json`: native extension metadata.

Chinese source text is the translation key. Use `t('找到 {count} 条收藏', { count })` for parameterized UI text. Keep placeholder names identical in the English entry. `translateError` handles errors at presentation boundaries; known already-formatted runtime messages are matched to catalog templates. Unknown Chinese system errors fall back to an English generic error in the English interface. Internal error matching and stored status codes stay stable.

Never pass saved titles, private notes, source content, or model answers through the translation system. Agent system prompts, tool descriptions, reranking instructions, and citation-repair instructions are written in English. Answers, clarification questions, and recommendation reasons follow an explicit output-language request, otherwise the user's current question (or the established language for an ambiguous follow-up). Source quotes remain verbatim. New AI summaries request the browser language; existing content is not rewritten. English instructions are a configuration choice, not a measured guarantee of better quality across models.

## Compatibility

The display name and package name are WebsiteStars / `websitestars`. Internal `starts` IndexedDB names, storage keys, message channels, and DOM markers remain unchanged to preserve existing data and integrations. Language choice is automatic and does not modify saved AI settings or enable remote requests.

## Verification

`tests/i18n.test.ts` covers locale resolution, fallback, interpolation, and persisted error translation. Existing UI regression tests explicitly use Chinese browser contexts. `tests/browser/i18n.spec.ts` exercises English interaction and language fallback in real extension pages. Add translations and corresponding coverage whenever adding a new system message.

项目默认跟随浏览器首选语言，中文地区统一使用简体中文，其他未支持语言回退英文。修改浏览器语言后重新打开扩展页面。界面与系统消息在显示时翻译，收藏内容不翻译；原数据库与设置标识保持兼容。新增文案需同时维护对应英文词典，动态参数使用命名占位符。
